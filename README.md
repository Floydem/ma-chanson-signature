# Ma Chanson Signature

Prototype bêta d'un service de chansons personnalisées.

## V1
- Site statique HTML/CSS/JS
- 3 formules
- Formulaire détaillé
- Upload jusqu'à 5 images pour la formule Signature complète
- Envoi gratuit via FormSubmit
- Aucun paiement en ligne
- Aucune API IA payante

## Formules
1. Chanson seule : 2 versions MP3
2. Chanson + paroles : 1 MP3 + vidéo karaoké MP4, 2e version en supplément
3. Signature complète : formule 2 + paroles PDF + jusqu'à 5 images personnalisées

## Important
Au premier envoi via FormSubmit, l'adresse de réception doit confirmer l'activation reçue par e-mail.
